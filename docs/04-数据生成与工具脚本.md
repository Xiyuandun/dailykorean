## 一、数据与产物全景

```
输入（人改的源）
├─ data/days_segments/day06~30.json     每天一个 JSON（第 6~30 天）
├─ tools/gen_days_template.py 内嵌 PLAN 数组（含第 1~5 天的词/文章/场景）
└─ tools/extra_scenes/group1~6.json     额外的附加场景分组

  发生处理：
   tools/gen_days_template.py   → data/days.js（30 天完整，window.DAY_PLAN）
   tools/gen_audio_fast.py      → audio/*.mp3 + data/audio.js（window.STATIC_AUDIO）

产物（勿手改，靠脚本重新生成）：data/days.js、data/audio.js、audio/*.mp3
```

## 二、数据源格式

### 2.1 分段 JSON（`data/days_segments/dayNN.json`）
每天一个对象，结构与 `days.js` 里每天一致：
```json
{
  "words":   [ { "word":"...", "phonetic":"...", "meaning":"...",
                 "example":"...", "exampleZh":"..." } ],
  "article": {
    "title":"...", "titleZh":"...",
    "paragraphs":[ { "en":"韩文", "phonetic":"读音", "zh":"中文" } ],
    "phrases":[ {"phrase":"...", "meaning":"..."} ],
    "grammar":[ {"point":"...", "explain":"..."} ],
    "tips":["..."],
    "quiz":{
      "choice":[ {"q":"...","options":["A","B","C","D"],"answer":0} ],
      "fill":[ {"q":"...","answer":"..."} ],
      "writing":{ "prompt":"...", "exampleAnswer":"..." }
    }
  },
  "scenarios":[
    { "scene":"场景名", "situationZh":"情境说明",
      "roles":{"clerk":"店员","user":"我"},
      "turns":[ {"role":"clerk","ko":"韩语","phonetic":"读音","zh":"中文"} ],
      "tips":[] }
  ]
}
```
- 每天 5 个场景，每场景 `turns` ≥6 句，必有 1 个 `user` 角色。
- 对话句读取兼容 `t.ko` 或 `t.en` 字段（`dialogue.js koOf()` 取 `ko||en`）。

### 2.2 extra_scenes 分组
- `tools/extra_scenes/group1~6.json` 是一些额外场景，通过 [merge_extra_scenes.js](file:///workspace/dailykorean/tools/merge_extra_scenes.js)（node 脚本）合并进 `days.js`。
- 合并要求：每天恰好新增 **3 个**场景、每场景 ≥6 句、字段齐全，合并后整天 5 个场景。
- 用 **node** 运行：`node tools/merge_extra_scenes.js`。

## 三、生成步骤（核心，可按需执行）

### 步骤 1：生成 `data/days.js`
```bash
cd /workspace/dailykorean
python3 tools/gen_days_template.py
```
- 读取内嵌 PLAN（day01~05）+ `data/days_segments/day06~30.json`，合并写 `data/days.js`。
- 脚本会做基础 JS 语法校验。
- 完成后 **`index.html` 里 `data/days.js?v=` 需 +1**。

### 步骤 2：生成韩语音频（预朗读 MP3 + 清单）
```bash
# 并发版（推荐，比逐一快数倍）：
python3 tools/gen_audio_fast.py [--voice ko-KR-SunHiNeural] [--concurrency 12] [--limit N]
# --limit N：可选，只生成前 N 条做冒烟测试；不写则全量。
# 旧版逐一声成：
python3 tools/gen_audio.py ko-KR-SunHiNeural
```
- 依赖 `edge-tts`（`pip install edge-tts`），生成阶段需联网访问微软服务（代理环境会自动读 `HTTPS_PROXY/HTTP_PROXY`）。
- 从 `data/days.js` 提取所有韩语文本 → edge-tts 韩语女声 `ko-KR-SunHiNeural`（或男声 `ko-KR-InJoonNeural`）→ 生成 `audio/*.mp3`。
- 文件名 = `sha1(规范化文本)[:16].mp3`；规范化为 `去首尾空白 + 连续空格压成单空格 + 小写`，与前端 `speech.js` 的 `_staticAudioPath` 一致。
- 写 `data/audio.js`（`window.STATIC_AUDIO.normal`）。
- 完成后 **`index.html` 里 `data/audio.js?v=` 需 +1**。

> ⚠️ 只要**韩语文本变了**，key 的 sha1 就变，对应 MP3 文件名变——必须重跑步骤 2，否则前端查不到新音频，只能回退到 Google/内置语音。

## 四、工具脚本清单与作用

| 脚本 | 语言 | 作用 |
|------|------|------|
| [gen_days_template.py](file:///workspace/dailykorean/tools/gen_days_template.py) | python | 分段源 → `data/days.js`（30 天内容） |
| [gen_audio.py](file:///workspace/dailykorean/tools/gen_audio.py) | python | 逐个 edge-tts 生成 MP3 + `audio.js`（旧版，慢） |

> 这些脚本/数据仅开发使用，**不随网页上传**（`.gitignore` 已忽略）。

## 五、新建"第 N 天"或修改内容的操作流
1. 编辑/新增 `data/days_segments/dayNN.json`（或 tools 内 PLAN / extra_scenes）。
2. 跑 `python3 tools/gen_days_template.py` 重新生成 `days.js`。
3. 若改了韩语原句：跑 `python3 tools/gen_audio_fast.py` 重新生成对应 MP3。
4. `index.html` 里 `days.js?v=`、`audio.js?v=`（以及被改模块的 `js?v=`）各 +1。
5. 可选：用 `--limit 2` 冒烟验证后全量。

## 六、注意事项
- **`audio/` 下千余个 MP3**：体积大、不可手改，只由工具生成。
- **`data/audio.js` 与 `data/days.js`**：都是脚本产物，别手改。
- edge-tts 生成依赖网络，断网/代理环境会失败；需保证可访问微软服务。
