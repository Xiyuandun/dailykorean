# DailyKorean · 每日韩语精进 — 项目总览与技术架构

> 本文档用于长期维护韩语网站。内容整理自源码、数据结构与开发记录，避免因对话丢失导致无法继续修复。
> 最后更新：2026-09-13

## 一、项目定位

一个**纯静态部署的韩语学习网站**（每日一更，30 天为一个内容周期）。帮助中文用户学习韩语，包含四大功能模块：今日总览（打卡）、单词训练、场景对话、文章阅读。网站**托管在 GitHub Pages**，无需后端即可运行，朗读靠预生成的 MP3 音频 + 浏览器语音合成，识别靠浏览器语音（可选接云端识别）。

- 项目路径：`/workspace/dailykorean/`
- 引擎类型：纯前端 HTML + JS + Tailwind CSS（CDN），无构建步骤，改完直接上传即可。
- 与 `dailyenglish`（英文站）**结构高度相似**，但内容为韩语、语音为韩语 TTS。两站独立目录、独立仓库、独立 Token。

```

├── css/app.css             # 少量自定义样式（约1KB，其余用 Tailwind CDN）

│   ├── store.js            # localStorage 状态管理 + 积分/连击/打卡 + Toast
│   ├── daycycle.js         # 30 天内容周期轮换：选当天内容、跨天重置
│   ├── speech.js           # 语音朗读（TTS）+ 语音识别（Vosk/Web Speech/可选云端）
│   ├── words.js            # 模块一：单词训练
│   ├── dialogue.js         # 模块二：场景对话（学习 + 默写考核）
│   ├── reading.js          # 模块三：文章阅读与测验（含简易写作为批改）
│   ├── report.js           # 学习报告
│   ├── app.js              # 主控制器：Tab 切换、初始化、全局事件
│   └── vendor/vosk-browser.js  # Vosk 离线语音识别库（约5.4MB）
├── data/
│   ├── days.js             # ★ 30 天全部内容（词/文章/场景），约 460KB（自动生成，勿手改）
│   ├── audio.js            # ★ 预置音频文件名清单 window.STATIC_AUDIO（自动生成）
│   └── days_segments/      # 第 06~30 天的分段 JSON 数据源（生成 days.js 的输入之一）
├── audio/                  # ★ 大量预生成韩语朗读 MP3（按 sha1 命名，千余个）
├── tools/                  # 18 内容生成 & 内置工具脚本（维护核心）
│   ├── gen_days_template.py    # 由 days_segments + 内嵌 PLAN → 生成 data/days.js
│   ├── gen_audio.py            # edge-tts 逐个生成韩语 MP3 + audio.js 清单（旧版）
│   ├── gen_audio_fast.py       # edge-tts 并发版生成（推荐）
│   ├── merge_extra_scenes.js   # 把 extra_scenes/group*.json 合并进 days.js
│   └── extra_scenes/           # 额外场景分组 JSON（group1~6）
├── fc_deploy/              # （可选）阿里云函数计算部署（云端识别后端，未上线）
└── docs/                   # 本文档目录
```

> `data/days.js`、`data/audio.js`、`audio/*.mp3` 均为**自动生成产物**，不要手改；改数据应改 `days_segments/` 源文件或用生成脚本重新生成。

## 三、运行原理（纯静态，无后端）

```
浏览器打开 index.html
   │
   ├─ daycycle.js 按"今天与基准日(EPOCH=2026-09-01)的差值 取模 30"选出当天内容
   │     → 把 DAILY_WORDS / DAILY_SCENARIOS / DAILY_ARTICLE 三个全局变量填成当天内容
   │     → 与本地记录 lastDay 不同则调用 Store.applyNewDay() 重置每日任务
   │
   ├─ 用户操作模块
   │     → words/dialogue/reading 读取当日全局变量渲染
   │     → 朗读调用 Speech.speak() / speakQueue()
   │     → 进度写回 Store（localStorage，按学习码隔离）
   │
   └─ 发音：优先播放 audio/ 下的预生成 MP3（最稳）
          → 无静态音频时走 Google 韩语 TTS（翻译接口，免费）
          → 失败降级：浏览器内置韩语语音 / 有道 TTS
```

## 四、30 天数据如何组织与生成（关键知识）

### 4.1 内容周期
- `DayCycle.EPOCH = '2026-09-01'`（[daycycle.js](file:///workspace/dailykorean/js/daycycle.js)）：视为周期第 1 天。
- `DayCycle.CYCLE = 30`，`READY_DAYS = 30`：30 天内容**已全部就绪**（当前 `data/days.js` 共 30 天）。
- 当天索引 = `(今天 - EPOCH) 取模 30`。比如 2026-09-13 是第 13 天。
- 当天内容不完整时 `getDay()` 会回退到已就绪内容取模，避免空白。

### 4.2 每天包含的数据（数据结构）
每天一个对象 `{ words, article, scenarios }`：
- `words`：10 个单词 `{ word, phonetic, meaning, example, exampleZh }`
- `article`：`{ title, titleZh, paragraphs[], phrases[], grammar[], tips[], quiz }`
  - `paragraphs[]`：`{ en, phonetic, zh }`
  - `quiz.choice[]`：`{ q, options[], answer(索引) }`
  - `quiz.fill[]`：`{ q, answer }`
  - `quiz.writing`：`{ prompt, exampleAnswer }`
- `scenarios[]`：5 个场景，每场景 `{ scene, situationZh, roles:{clerk,user}, turns[], tips[] }`
  - `turns[]`：`{ role:'clerk'|'user', ko, phonetic, zh }`（每场景 ≥6 句）

当前统计：30 天 × 5 场景 = **150 个场景**；day01 有 10 词、4 段文章。

### 4.3 生成链（改内容必须走这套，别手改 days.js）
```
days_segments/day06~30.json   ← 每天一个 JSON（可手动编辑/新增）
        │
        │  python3 tools/gen_days_template.py
        │  （内部 PLAN 数组含 day01~05 + 合并 days_segments 的 day06~30）
        ▼
   data/days.js（30 天完整内容，勿手改）
        │
        │  python3 tools/gen_audio_fast.py [--voice ko-KR-SunHiNeural] [--concurrency 12]
        │  （从 days.js 提取所有韩语文本 → edge-tts 生成 MP3 → 写 data/audio.js 清单）
        ▼
   audio/*.mp3  +  data/audio.js（window.STATIC_AUDIO.normal 清单）
```

- 额外场景：`tools/extra_scenes/group*.json` → 交给 `node tools/merge_extra_scenes.js` 合并（需每天恰好 3 个新场景，每场景≥6句，字段齐全），合并后总场景数应每天 5 个。

> ⚠️ 前端用 webaster 的 `_staticAudioPath()` 会以"文本规范化后的 key"查找 `audio.js` 里的文件名（去空格、统一小写）。生成脚本的 `norm()` 与之一致，因此**一旦文本改动，音频文件名（sha1(key)) 会变，需重新生成对应 MP3**。

## 五、四大功能模块（详见 docs/01-功能模块详解.md）
1. **今日总览（home）**：打卡 + 周连击 + 今日任务列表。
2. **单词训练**：逐词浏览（朗读/慢速）→ 6 题测验（听选词/译选词/听选义）→ 完成页 + 下载 PDF。
3. **场景对话**：学习页（先中文后看韩语，逐句/整段朗读）→ 默写考核页（根据中文默写韩语，全部正确即完成）。
4. **文章阅读**：韩语文章 + 读音 + 中文对照 + 短语/语法/易错 + 读后测验（选择/填空/写作）。

## 六、语音方案（详见 docs/02-语音与语音识别方案.md）
- **朗读（TTS）**：预生成 MP3 > Google 韩语 TTS > 浏览器内置韩语 > 有道 TTS。
- **识别（STT）**：默认纯前端——安卓走 Vosk 离线（40MB 模型）/ 浏览器 Web Speech 优先；可接入阿里云 DashScope（需后端 FC，`window.DAILY_CFG.sttUrl` 未配置则关闭）。**当前 sttUrl 未配置，安卓识别体验受限。**

## 七、部署（详见 docs/03-部署与维护指南与常见修复.md）＋数据生成见 docs/04-数据生成与工具脚本.md
- 目标：GitHub Pages（静态），**只需上传 index.html + css/ + js/ + data/ + audio/（及必要时 models/）**。
- 后端脚本（server.py / fc_deploy / requirements / tunnel / render.yaml / vercel.json）**不进仓库部署**（已在 .gitignore 忽略）。
- 改 JS 后需**把 index.html 对应 `<script src="js/xxx.js?v=N">` 版本号 +1**，强制浏览器加载新脚本（GitHub Pages 有缓存）。
