# DailyKorean · 功能模块详解

> 本文档详细说明四大功能模块的交互流程、状态数据与关键代码位置，便于后续修复与扩展。

---

## 模块一：单词训练（`js/words.js` · `WordModule`）

### 交互流程
1. **浏览**：逐词展示 `{ word, phonetic, meaning, example, exampleZh }`，卡片有"朗读 🔊"和"慢速 🐢"按钮，调用 `Speech.speak(word)` / `Speech.speak(word, 0.6)`。
2. **前后翻**：`prev()`/`next()`，进度写入 `Store`（`wordIndex`）。
3. **测验**：学完所有词后进入，固定 **6 道题**，题型按 `quizIdx % 3` 循环：
   - 题型 0：听韩语音频 → 选对应韩语单词
   - 题型 1：看中文释义 → 选对应韩语单词
   - 题型 2：听韩语音频 → 选对应中文释义
   - 每道题 4 个选项（正确 + 3 个干扰项，随机洗牌）。
4. **完成页**：显示答对数，可下载 PDF（浏览器打印实现）。

### 关键状态（写进 Store）
| 字段 | 含义 |
|------|------|
| `wordIndex` | 当前学到第几个词 |
| `wordQuizDone` | 本日测验是否完成 |
| `wordCorrect` | 答对题数 |

### 关键代码
- 总数显示动态化：`WordModule.init()` 用 `DAILY_WORDS.length` 填充标题/进度/完成页的"总数"（[words.js L12-17](file:///workspace/dailykorean/js/words.js#L12-L17)），避免写死 10 与当天实际词数不一致。
- 完成时调用 `Store.recordTask('word')` 发放 +20 积分。

## 模块二：场景对话（`js/dialogue.js` · `DialogueModule`）

> 与英文站不同：韩语站**不采集录音/无语音识别**，考核方式改为"根据中文默写韩语"。

### 学习页（study）
- 展示对话场景的身影，气泡按 `role` 分左右：`clerk`（店员/服务者）在左，`user`（我）在右。
- 默认**只显示中文**；点"👀 显示韩语对照"后展开韩语句 + 读音 + 每句 🔊 朗读。
- 可"🔊 朗读整段"（`Speech.speakQueue` 顺序朗读所有韩语句）和"⏹️ 停止"（`Speech.stop`）。
- 显示韩语时"进入默写考核"按钮才可用。

### 默写考核页（quiz）
- 每句显示中文，用户须在输入框**用韩语默写**。
- 校对：`_norm()` 规范化后严格相等（去空格、标点、英文、连字符、统一小写）。
  ```js
  _norm(s) { return (s||'').replace(/[\s\u3000，。！？、；：""''（）a-zA-Z·-]/g,'').toLowerCase(); }
  ```
- 点"✅ 检查答案"逐句判定；**全部正确** → `completeScene()`；某一场景完成则逐步完成标记。
- 全部场景完成（本日全部 5 个）→ `Store.recordTask('dialogue')` +20 积分。

### 关键字段兼容
- 数据里句子文本取 `t.ko || t.en`（`koOf()`），兼容两种字段名。

## 模块三：文章阅读（`js/reading.js` · `ReadingModule`）

### 页面内容
1. **韩语文章**：分段展示，每段 `{ en(韩文), phonetic(读音), zh(中文) }`；点段落或 🔊 可单句朗读。
2. **全文朗读 / 慢速**：`readAll(1)` / `readAll(0.6)`，用 `Speech.speakQueue(`各段韩文`)`。
3. **重点短语 / 语法 / 易错提醒**：三块静态展示。
4. **读后测验**：
   - 选择题：`quiz.choice[]`，点选即判分。
   - 填空题：`quiz.fill[]`，输入韩语，`toLowerCase()` 精确匹配（[reading.js L140-154](file:///workspace/dailykorean/js/reading.js#L140-L154)）。
   - 写作题：`quiz.writing`，写 3-5 句韩语，"AI 批改"实为**本地规则评分**（长度/句数/关键词/标点，撑口 10 分），非真 AI。得分存入 `writeScores`。
5. 三类题全部完成 → `Store.recordTask('reading')` +20 积分。

### 关键点
- `ReadingModule.init()` 里 `Speech.clearCache()` + `Speech.prefetch(各段, 1)` 预缓存整篇，点读秒播。
- 写作关键词硬编码在 [reading.js L185-195](file:///workspace/dailykorean/js/reading.js#L185-L195)（示例文章 `octopus` 等），**若改文章主题需同步更新这批关键词**，否则批改纪律命中为若干，分数偏保守。

## 顶层 API：状态管理（`js/store.js` · `Store`）与通知（`Toast`）

### 学习码隔离
- `currentUser`：localStorage key `dailykorean_state_v1`（默认）+ `dailykorean_state_v1_<学习码小写>`（登录后）。
- 同一设备不同使用者输入不同学习码，各自独立进度。

### 状态字段（`Store.get()` 返回对象）
```js
{
  points, streak, lastCheckin,
  weekHistory: [{date, words, dialogue, reading}],
  tasks: {word, dialogue, reading},   // 每日任务完成标记
  wordIndex, wordQuizDone, wordCorrect,
  pronCount, writeScores: [],
  lastDay,        // 上次内容周期索引；跨天重置每日任务用
  dark,           // 主题
  voice: 'sunhi'  // 朗读语音
}
```

### 重要方法
| 方法 | 作用 |
|------|------|
| `setUser/getUser` | 切换/读取学习码 |
| `applyNewDay(dayIndex)` | 周期索引变化时**重置每日任务**（wordIndex/wordQuizDone/tasks），积分等长期数据保留 |
| `recordTask(type)` | 标记任务完成，+20 积分 |
| `checkin()` | 打卡，+10 积分，更新连击 & 周历史 |
| `refreshBadges()` | 刷新积分/连击/任务状态 UI |

### 跨天重置逻辑（重要）
`DayCycle.bootstrap()` 每天调用 `Store.applyNewDay(idx)`。若 `lastDay !== 今天索引` 则清空 `tasks/wordIndex/wordQuizDone`——保证**每天重新开始当日三任务**，但连击/积分/周历史长期累计。

## 顶层 API：主控制器（`js/app.js`）
- `switchTab(name)`：切换模块前**停止朗读 + 停止录音回放 + 停止识别**（[app.js L3-8](file:///workspace/dailykorean/js/app.js#L3-L8)）。
- `DOMContentLoaded` 里 `Speech.init()`、绑定学习码/主题/语音选择/打卡、`DayCycle.bootstrap()`、初始化各事件。
- 页面离开/隐藏时 `Speech.stop()`（`beforeunload`/`pagehide`/`visibilitychange`），避免后台继续播放。

---

## 各模块与"当日数据全局变量"的关系
- `daycycle.js` 把当天内容写入：
  - `window.DAY_PLAN`（30 天完整数组）
  - `window.DAILY_WORDS` / `window.DAILY_SCENARIOS` / `window.DAILY_ARTICLE`（当天切片）
- 三个功能模块**只读当天的 `DAILY_*` 全局变量**渲染，所以每模块代码无需感知是哪一天。
- 新增第 X 天内容 = 更新 `days_segments` 源 + 重新生成 `days.js` 即可，模块零改动。
